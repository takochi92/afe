# 案件リンクの置き方（ブログ）

## しくみ
- 記事の本文に、`[リンクの文字](aff:キー)` と書く。キーは `blog/affiliate.json` にある：`sbi-kodomo`（SBI証券 こども口座）、`matsui`（松井証券）、`rakuten`（楽天証券）、`smbc-nl`（三井住友カード）
- `affiliate.json` の `url` が **空のあいだは、リンクにならず、ただの文字として出る**（提携前に、誤ってリンクが出ることはない）
- `url` を入れると、自動で `rel="sponsored nofollow noopener"` のリンクになり、「PR」の小さな印が付き、その記事の冒頭に「本記事はアフィリエイト広告（PR）を含みます。」が出る

## 提携が決まったあと（オーナー → 社長）
1. ASPの管理画面で、その案件の「広告リンク（テキストリンクのURL）」をコピーする
2. 会社サイトの指示欄に、キー名とURLを貼って送る（URLはパスワードではないので貼ってよい。ログインの情報は貼らない）
3. 社長が `affiliate.json` に入れて公開する

## 守ること
- 提携が決まっていない案件の `url` は、空のままにする
- 広告主・ASPの規約（リスティング禁止、SNSへの掲載条件、指定の表記）に従う。SBI証券こども口座は「リスティングNG」
- 個別商品のおすすめ・勧誘・断定をしない。記事は「制度と手続きの整理」の形のまま、リンクは「口座の開設ページはこちら」の程度にとどめる
- SNSの投稿の本文にはリンクを載せない（プロフィールのリンク欄からブログへ）
