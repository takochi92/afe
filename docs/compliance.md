# コンプライアンス規程

アフィリエイトは広告です。法令違反は広告主・ASP・当社すべてに損害を与え、提携解除や行政処分につながります。
**検品部はこの文書を基準に判定します。**

> 注意：本書は社内の実務ルールであり法的助言ではありません。判断に迷う表現はオーナーに確認し、必要に応じて専門家に相談してください。

## 1. ステマ規制（景品表示法・2023年10月1日施行）

- 広告であることを明示する。記事冒頭（タイトル直下）に以下を必ず記載：
  > 本記事はアフィリエイト広告（PR）を含みます。
- 「広告であることが分かりにくい」表記（極小文字、記事末尾のみ、ハッシュタグに紛れ込ませる等）は不可

## 2. 景品表示法（優良誤認・有利誤認）

| NG例 | OK例 |
|------|------|
| 業界No.1 | 〇〇調査（2026年5月）で満足度1位 ※出典リンク |
| 最安値 | 2026年10月時点で当社調べの主要5社中もっとも安い |
| 誰でも必ず稼げる | 成果には個人差があります |
| 今だけ！（期限不明） | 2026年10月31日までのキャンペーン |

## 3. 薬機法（健康食品・サプリ・化粧品・美容機器）

- 効能効果の断定・医薬品的表現は禁止：「痩せる」「治る」「シミが消える」「髪が生える」「免疫力アップ」「アンチエイジング」
- 化粧品は承認された効能の範囲内（例：「肌にうるおいを与える」）
- 健康食品は「〇〇をサポート」程度でも、病名と結びつけない
- ビフォーアフター写真は原則使わない

## 4. その他の法令・規約

- **金融（FX・投資・カードローン等）**：利回り保証表現禁止、リスク説明必須
- **著作権**：他サイトの文章・画像の無断転載禁止。引用は主従関係を守り出典明記
- **ASP・広告主規約**：自己アフィリエイト可否、リスティング出稿禁止、指定NGワードを `sales/programs.md` で確認
- **体験談**：実際に体験していないことを体験したように書かない。口コミは出典を示して引用

## 5. 価格・情報の鮮度

- 価格・キャンペーン・スペックは「YYYY年MM月時点」を付ける
- 公開から6か月経過した記事はリライト候補として記録部が抽出する
