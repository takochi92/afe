# こどもNISA「事前申込と制度開始」記事の拡散運用

開始: 2026-10-13。対象記事: https://kodomo-okane-note.site-kanri19.workers.dev/kodomo-nisa-jizen-2027/

## まず公開する

1. Instagram: 検品済み6枚カルーセル `posts/ig/2026-10-14-kodomo-nisa-jizen.md`。次回の自動起動で投稿候補とする。投稿前に `records/ig_posts.csv` とアカウントを確認する。
2. Threads: `posts/queue/INDEX.md` の08、09、10を順番に、異なる日に投稿する。画像は各原稿の公開URLを使う。08は誤解の訂正、09は手続き前の確認、10は年間枠の意味。
3. 公開URLと日時を必ず `records/ig_posts.csv` / `records/posts.csv` / `posts/queue/INDEX.md` に記録する。投稿済みなら再投稿しない。API失敗時は公開状態を確認してから再試行する。

## 人の目に入るための動き（投稿直後）

- Threadsの08〜10には画像とトピック `こどもNISA` を付ける。08の最後は「受付と開始、どちらが紛らわしかった？」と問いかけ、返信には出典を示して具体的に答える。Metaは返信参加とトピック付き投稿が発見に役立つと公表している。相手の質問に答える場では、まず答えを書き、必要な場合だけ記事リンクを添える。無関係な投稿への一律返信はしない。
- Instagramカルーセル公開後、プロフィールのリンクが記事またはブログに向いているか確認する。公開後にストーリーズで1枚目と「申込開始＝投資開始ではない」の要点を紹介し、記事へのリンクを添える。ストーリーズは現在のAPIスクリプトの対象外のため、実施した場合だけ記録する。
- 子育て・金融教育の発信者や編集者に共有する場合は、相手の直近の発信と接点を確認し、短い個別の文面で図解の利用可否を伝える。相手への連絡はオーナーの明示的な承認を得てから行う。
- 08〜10の投稿時にプロフィールの「こどものお金ノート」導線と、画像1枚目の表示を確認する。見えない場合は公開後の記録に原因と対応を書く。

## 記事への入口

- Threads本文のリンクには `utm_source=threads` を付けた。クリックを増やすため、本文の最初の一文で疑問を提示し、図解と出典を記事で確認できるようにした。
- Instagramは6枚の図解を先に見せ、詳しい根拠を読む人にはプロフィールから「こどものお金ノート」へ案内する。プロフィールに記事またはブログのリンクが設定されているか投稿時に確認する。
- 記事内の共有ボタンは `utm_source=reader_share` を付ける。OG画像はカルーセル1枚目、X等では大きいカードを指定した。
- ブログ内の関連記事導線から、ジュニアNISAとの違いや払出し条件へ回遊できる。

## 24時間後と72時間後に記録する

各投稿の表示数、保存数、シェア数、返信数、プロフィール訪問数、リンククリック数（取得できる項目だけ）を、確認日時とともに記録する。未取得の値は空欄にする。記事はアクセス元別の訪問数、記事から関連記事へ進んだ数を、利用できる解析環境で確認する。公開URLが出る前に成果を推測しない。

## 次の投稿を選ぶ

- 保存や返信が多ければ、その投稿で実際に聞かれた質問を1つ選び、公式資料で確認して別の記事・図解にする。
- クリックが少なければ、投稿の最初の一文とブログへの案内を見直す。本文・画像を同じ日に大量再投稿しない。
- 申込方法などが変わったら、元記事を先に更新し、更新日と出典を記す。古い説明をそのまま再配信しない。
- 数値目標は、実測の初回3本を基準に設定する。伸びを保証する表現や、根拠のない「お得」「今すぐ買える」は使わない。
