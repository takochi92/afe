# 文体・品質ガイド

## 基本方針

- 読者の悩みを最短で解決する。**結論 → 理由 → 具体例 → 行動** の順
- 売り込みより信頼。デメリット・向かない人も正直に書く
- 「誰に」「何を」おすすめするかを明確に（「〇〇な人には A、△△な人には B」）

## 文体

- です・ます調で統一
- 1文60字目安、1段落3〜4文まで
- 漢字:ひらがな ≒ 3:7。「出来る→できる」「下さい→ください」「事→こと」
- 数字は半角、単位は全角に合わせない（例：3,980円、10GB）
- 「〜と思います」の多用禁止。根拠がある内容は言い切り、ないことは書かない

## 記事構成の型

1. 冒頭：PR表記 → 読者の悩みへの共感（2〜3文）→ 結論（おすすめと理由）
2. 本文：比較表・選び方・各商品の詳細（メリット／デメリット／向いている人）
3. よくある質問（FAQ）
4. まとめ：結論の再提示とCTA

## SEO

- タイトル：32文字前後、メインKWを前半に
- メタディスクリプション：120字以内、KWと記事のベネフィットを含める
- H2 にはKWまたは関連KWを自然に含める（詰め込み禁止）
- 内部リンクを最低2本（関連記事がある場合）

## アフィリエイトリンク

- 原稿では `[[AFF:案件名]]` プレースホルダを使う
- CTAボタン文言は具体的に（「公式サイトで料金を見る」「無料体験を申し込む」）
- 1記事の同一案件リンクは目安3か所まで（冒頭結論・詳細・まとめ）
