# 投稿ストック（Threads）

毎朝の自動投稿は、この表の「使える」ものから1件ずつ使う。使ったら「投稿済み」にURLを書く。
**使える条件**：検品が合格 かつ 公式確認が「済」または「不要」。公式確認が「待ち」のものは、オーナーが「研究資料の内容で出してよい」と決めるか、公式サイトで確認できるまで使わない。

| 番号 | 題材 | 検品 | 公式確認 | 投稿済み |
|---|---|---|---|---|
| 01 | 親の口座が別の会社 | 合格 | 待ち（PayPay証券・SBI証券の例外、1人1口座） | |
| 02 | 祖父母が出すとき | 合格 | 待ち（国税庁：基礎控除は受贈者ごと年110万円、同年の贈与は合算） | |
| 03 | きょうだいが2人以上 | 合格 | 待ち（1人1口座・1金融機関、枠は子ども1人ごと） | |
| 04 | ジュニアNISAとの違い | 修正済み・再検品待ち | 待ち（80万・5年、無期限、受付終了） | |
| 05 | 12歳からの払出し | 修正済み・再検品待ち | 待ち（税制改正大綱と成立した法律・政令） | |
| 06 | 児童手当を積み立てる | 合格 | 不要（制度の数字を使わない一般的な注意） | |
| 07 | 18歳になったら | 合格 | 待ち（金融庁資料：18歳で自動移行） | |

## 使い方
- 投稿文は各ファイルの「## 投稿文」の節だけを使う（冒頭の「修正済み」の行は使わない）
- 画像は `scripts/make_card.js` で、各ファイルの「## カード」の1行JSONから作る
- 公式確認の対象ドメイン（fsa.go.jp / mof.go.jp / nta.go.jp / caa.go.jp）は、環境のネットワーク設定で許可すると、私が直接確認できる
