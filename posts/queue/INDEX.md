# 投稿ストック（Threads）

毎朝の自動投稿は、この表の「使える」ものから1件ずつ使う。使ったら「投稿済み」にURLを書く。
**使える条件**：検品が合格。公式確認は、オーナーが「許可したことにしてくれ。じゃんじゃん投稿可能」と指示した（2026-10-11）ため、**待たずに調査資料の内容で使ってよい**。公式サイトが開けたら、その時点で確認して、食い違いがあれば直す。**例外：02（贈与税）は、監修が決まるまで使わない（オーナー指示：監修は保留）。**

|---|---|---|---|---|
| 01 | 親の口座が別の会社 | 合格 | 省略（オーナー承認。後で公式を確認） | |
| 02 | 祖父母が出すとき | 合格 | **使わない（税の話。監修が決まるまで保留）** | |
| 03 | きょうだいが2人以上 | 合格 | 省略（オーナー承認。後で公式を確認） | |
| 04 | ジュニアNISAとの違い | 修正済み（再検品は軽い確認で済む） | 省略（オーナー承認。後で公式を確認） | |
| 05 | 12歳からの払出し | 修正済み（再検品は軽い確認で済む） | 省略（オーナー承認。後で公式を確認） | |
| 06 | 児童手当を積み立てる | 合格 | 不要（制度の数字を使わない一般的な注意） | |
| 07 | 18歳になったら | 合格 | 省略（オーナー承認。後で公式を確認） | |

## 使い方
- 投稿文は各ファイルの「## 投稿文」の節だけを使う（冒頭の「修正済み」の行は使わない）
- 画像は `scripts/make_card.js` で、各ファイルの「## カード」の1行JSONから作る
- 公式確認の対象ドメイン（fsa.go.jp / mof.go.jp / nta.go.jp / caa.go.jp）は、環境のネットワーク設定で許可すると、私が直接確認できる

推奨の順番: 06 → 03 → 07 → 01 → 04 → 05（02は保留）。使えるものが尽きたら、リサーチ資料から新しく作る（手順は docs/daily-sns-routine.md）。
