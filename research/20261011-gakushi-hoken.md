## 1. 学資保険の仕組み（事実）
出典はすべて生命保険文化センター（以下、生保文化センター）。「こども保険」のページが、学資保険にあたる。

| 項目 | 内容 | 出典（確認日 2026-10-11、検索抜粋） |
|---|---|---|
| 受取の形 | 入学・進学に合わせて祝金や満期保険金を受け取るタイプと、18〜22歳など数年間、毎年祝金（学資年金）を受け取るタイプがある | https://www.jili.or.jp/knows_learns/kind/main/32.html |
| 満期金と祝金 | 一般に満期保険金のほうが祝金より多い。毎年祝金を受け取るタイプでは、祝金と満期金が同額のものが多い | 同上 |
| 払込免除 | 親などの契約者が亡くなった場合、その後の保険料の払込みが免除されるのが一般的。満期まで育英（養育）年金や一時金を受け取れるものもある | 同上 ／ https://jili.or.jp/knows_learns/q_a/life_insurance/154.html |
| 払込免除の範囲 | 死亡のほか、高度障害や不慮の事故による障害状態でも免除される場合がある。**条件は会社・商品ごとに違う** | 同上（Q&A）、特約のページ https://www.jili.or.jp/knows_learns/kind/special/9257.html |
| 元本割れの注意 | 「祝金や満期保険金の受取総額が、払い込んだ保険料総額を下回ることがあります」と、生保文化センターが注意している | https://www.jili.or.jp/knows_learns/kind/main/32.html |
| 中途解約 | 解約返戻金は通常、払い込んだ保険料総額より少ない。契約して間もないと、ほとんどないか、ごくわずかなこともある | 解約のページ https://jili.or.jp/knows_learns/basic/continuance/96.html |
| 返戻率 | 受取総額÷払込保険料総額。多くの学資保険は契約時に決まる（変額型は別。運用次第で下回るおそれがある） | 富国生命の解説 https://www.fukoku-life.co.jp/plan/tsubasa/basic/trivia26/ ／ 生保文化センターの変額保険の説明 https://www.jili.or.jp/knows_learns/kind/main/29.html |
| 返戻率が変わる条件 | 加入時の子の年齢、払込期間の長さ、払い方（まとめ払いなど）。高めるには短期払いが必要なことが多く、家計の負担が重くなる場合がある | 第一生命の解説 https://www.dai-ichi-life.co.jp/promotion/first_step/choice/00008/index.html ほか |
| 返戻率の見方 | 100%を超えれば払込総額より多く受け取れる、という意味。ただし返戻率だけで比べるのはすすめない（富国生命の解説） | https://www.fukoku-life.co.jp/plan/tsubasa/basic/trivia6/ |

### 返戻率の「例」（1つだけ）
- ソニー生命は「2026年4月2日以降の契約の一例」として、0歳加入で返戻率127.4%という例を示している、と検索結果の要約にあった。同社は契約条件によって下回ることも注意している。
- **未確認**：原文のページで数字・条件（払込期間、払い方）を見ていない。記事に使うなら、条件つきで、公式ページ https://www.sonysonpo.co.jp/groupad/gakushi/ を再確認してから。使わなくてもよい。
- 「かつては返戻率120%超もあったが、いまは100%前後が目安」という専門家の見方もある（第一生命の解説記事、約4年前の記事とされる。時期で水準が違う）。

## 2. こどもNISAの性質（research/20261010-kodomo-nisa.md の範囲）
元の調査も検索抜粋ベース。数字は公式で再確認が必要（確認日 2026-10-10）。
- 対象は0〜17歳。開始は2027年1月。根拠は令和8年法律第12号（2026年3月31日成立）。財務省 https://www.mof.go.jp/tax_policy/summary/income/nisa_2.pdf ／ 金融庁 https://www.fsa.go.jp/news/r7/sonota/20251226-2/01.pdf
- 枠：年間60万円、非課税保有限度額600万円（0〜17歳の間）
- 対象商品：つみたて投資枠の対象の投資信託に限る。個別株は買えない
- 払出し：原則18歳まで払い出せない。12歳以降は、子のために使うことと子の同意を示す書面を付けて、親権者等が申し出れば払い出せる
- **元本は保証されない**：金融庁の資料では、投資信託は元本が保証されず、価格が日々変わるとされる（下の3-A）。
- 親に万一のことがあったときの自動の払込免除のような仕組みは、こどもNISAにはない（比較解説の記述。制度側の公式文書では未確認）。

## 3. 比べる「軸」と、根拠にできる資料
結論：次の5つ。どれも「どちらがよい」ではなく「自分の家はどうか」を考える質問にする。

| 軸 | 質問の形 | 根拠にできる資料 |
|---|---|---|
| ① 必要な時期 | 「いつ、いくら必要か決まっているか」 | 金融庁の入門資料：生活費や、近く使い道が決まっているお金と、当面使わないお金を分けて考える（下の3-A）。比較解説の例：大学入学の5年前から運用の割合を下げ、3年以内に使う分は預金に移す、という出口の考え方（民間の解説。公的ではない） |
| ② 値下がり／確実さ | 「値下がりを受け入れられるか、確実さを優先するか」 | 金融庁：預金は元本保証で安全性が高いが収益性は低い。投資信託は元本割れのリスクがある。5年程度の短期では元本割れがありえるが、20年では1989年以降のデータで元本割れはなかった、とされる（過去の実績で、将来を保証しない。書くなら出典と期間つきで） |
| ③ 保障 | 「親に万一のことがあっても、教育費の準備を続けたいか」 | 生保文化センター：契約者が亡くなると以後の保険料が免除されるのが一般的（上の1） |
| ④ 使える期間・途中で使えるか | 「途中で使う可能性はあるか」 | 学資保険：途中解約は通常払込総額より少ない。こどもNISA：原則18歳まで払出し不可、12歳以降は条件つき。どちらも「いつでも自由に」ではない |
| ⑤ 家計の余裕と併用 | 「毎月いくら出せるか。分けることはできるか」 | 公的資料での併用の考え方は **未確認**。民間の解説に「目標額を半分ずつ」の例がある程度。記事では「分ける考え方もある」と事実だけ書き、割合は示さない |

## 4. 気をつける点（書き方のルール）
- **断定しない**：「こどもNISAのほうがお得」「学資保険は損」「学資保険のほうが安心」は書かない。「どちらがよいか」は家庭で違う、と書く。
- **勧誘にならない**：保険商品の説明・勧誘は外務行為や保険業法の問題になりうる。個別商品の名前・返戻率の比較表は載せない。返戻率の例を出すなら、1つだけ、条件と時点つきで。保険会社の案件を載せるかは営業部へ（保険業法は要確認）。
- **税の話は書かない**：控除や贈与税は監修が決まるまで出さない（CLAUDE.md）。
- **将来の運用成績の数字を作らない**：「年○％で運用すると○円」のような試算は載せない。過去の実績を出すなら、金融庁の資料の言い回しと期間つきで。
- **既存の学資保険を解約する話**：知恵袋では「やめて切り替えてよいか」の悩みが多い（research/20261011-kodomo-nisa-voices.md テーマ1）。記事では「解約する前に、戻る額を契約した会社に確認する」という事実までにして、「やめるべき」とも「続けるべき」とも書かない。
- こどもNISAの名称・払出し違反時の課税・開始日は、まだ確認中の点がある（research/20261010-kodomo-nisa.md）。「予定」「確認中」と書く。
- アフィリエイトリンクを置くなら、記事冒頭に「本記事はアフィリエイト広告（PR）を含みます」を入れる。

## 5. 記事の骨組み案（参考。最終はplannerへ）
タイトル案：「こどもNISAと学資保険、どう比べる？ 迷ったときの3つの見方」
3つの見方の候補（軸①〜⑤を3つにまとめる）：
1. いつ使うお金か（軸①④）
2. 値下がりと確実さ、どちらを大事にするか（軸②）
3. 万一のときの備えが必要か、家計にどれだけ余裕があるか（軸③⑤）
冒頭に結論：「どちらが正解かは、家庭によって違います。この記事は、考えるための3つの見方を紹介します」。
