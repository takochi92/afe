# 証券各社の案件確認シート（t04、オーナー用）

目的：ASPの管理画面で、各社の案件条件を見て、この表に書き写す。**書き写した内容を会社サイトの指示欄に貼ってもらえれば、営業部が `sales/programs.md` に反映する。**
所要：登録済みのASPごとに約10分。ログインIDやパスワードは書かない（見せない）。

## 手順（ASPごとに繰り返す）
1. 登録済みのASPを、下の「0. 登録状況」に○をつける（登録していないASPは飛ばす）
2. そのASPの管理画面にログイン → 「プログラム検索（案件検索）」を開く
3. 下の8社を1社ずつ検索する（「SBI証券」「楽天証券」「マネックス証券」「松井証券」「三菱UFJ eスマート」または「auカブコム」「moomoo」「PayPay証券」「大和コネクト」）
4. 見つかった案件ページで、下の「1. 書き写す項目」を表にメモする
5. 提携申請が要る案件は、申請ボタンを押す前に、会社サイトで一声かける（掲載先にSNS・ブログ・リンクを書く欄があるため）

## 1. 書き写す項目（案件ごと）
- 案件名（ページの表記のまま）
- 報酬額（成果地点ごと。「口座開設」「口座開設＋入金」など）
- 成果の条件（承認の条件。入金額・取引の条件）
- 承認率・承認までの期間（書いてあれば）
- **未成年口座・こどもNISA口座は成果の対象か**（書いてなければ「記載なし」）
- 提携状況（提携済／申請が必要／提携不可）
- 掲載してよい媒体（SNS・ブログ・無料ブログ・メール）
- リスティング広告の可否と、禁止キーワード（社名・サービス名など）
- 指定の表記や、使ってはいけない表現（PR表記・リスク説明）
- 掲載が終わる日（案件の終了日）があれば

## 2. 書き写す表（コピーして使う）
| ASP | 案件名 | 報酬 | 成果条件 | 未成年口座が対象か | 提携状況 | 媒体（SNS・ブログ） | リスティング | 禁止・指定表記 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

## 3. 迷ったとき
- 案件が見つからない → 「見つからず」と書く。それも大事な情報
- 数字が2つある（通常・キャンペーン） → 両方書いて、キャンペーンの期間も書く
- 金額が高い案件でも、SNSへの掲載が禁止なら、ブログだけで使う（営業部が整理する）

## 4. 回答を受け取ったあと（営業部）
- `sales/programs.md` の該当行に、報酬・成果条件・禁止事項・確認日を反映する
- 親の口座が起点になる案件は、企画部に導線の見直しを渡す
